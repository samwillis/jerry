# Jerry 0.1.3 — Jerry On Line

Jerry’s expedition journal can now travel with you.

- Connect to an optional, self-hosted **Jerry On Line** server to read your journal in a browser as Jerry writes it. The web journal brings over the handwriting, taped directions, expandable details and Polaroids from the Mac.
- Share new expedition notes as they’re saved. Choose whether to also share older expeditions, photos and technical details. Jerry keeps saving locally if the server is unavailable.
- Start an expedition, add a direction or stop Jerry from the browser when you’ve enabled **Allow remote missions** on the Mac. Remote missions start disabled at each launch and pause when you take manual control.
- Switch back to Settings or the Journal with Command–Tab. Jerry returns to menu bar mode when you close the last window.

To get online, enter your server’s address in **Settings → Jerry On Line**. See the [JOL hosting guide](https://github.com/samwillis/jerry/blob/v0.1.3/docs/JOL_SETUP.md) to run your own server on Neon. No JOL account or server is needed to use Jerry locally.

## Download

Download **Jerry-v0.1.3-macos-universal.zip**, unzip it, quit your previous copy and move **Jerry.app** to Applications.

Requires macOS 14 or later. The universal app is signed by Flutterbox Ltd. and notarised by Apple. The release was tested on Apple Silicon. **SHA256SUMS.txt** contains the archive checksum.
